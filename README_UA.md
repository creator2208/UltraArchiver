# UltraArchiver

Україномовний архіватор для Windows 10/11 з темним графічним інтерфейсом.

## Функції
- Створення 7z, ZIP, TAR, WIM, XZ, GZIP та BZIP2.
- Розпакування форматів, які підтримує 7-Zip, зокрема RAR, 7z, ZIP, TAR, TGZ, ISO та CAB.
- Рівні стиснення 0–9.
- Додавання файлів і папок, вибір місця збереження.

## Запуск із Python
1. Встановіть Python 3.10+.
2. Встановіть 7-Zip: https://www.7-zip.org/
3. Запустіть `run.bat` або `python ultraarchiver.py`.

## Збірка Windows EXE
GitHub Actions автоматично збирає portable-пакет після кожного push у `main`.
Готовий ZIP з `UltraArchiver.exe`, `7z.exe` і `7z.dll` буде доступний у вкладці **Actions → останній успішний запуск → Artifacts**.

Локальна збірка: запустіть `build_exe.bat`.

## Обмеження
Стиснення 5–10 ГБ до 20–70 МБ не можна гарантувати: результат залежить від вмісту. RAR підтримується для розпакування, але не для створення.
